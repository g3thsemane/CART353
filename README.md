# CART353

A React + Vite project using JavaScript and JSX.

## Getting started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Edit `src/App.jsx` to begin; changes appear automatically in the browser.

## Commands

- `npm run dev` starts the development server.
- `npm run build` creates a production build in `dist/`.
- `npm run preview` serves the production build locally.
- `npm run lint` checks the source code with Oxlint.
